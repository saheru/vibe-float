Vibe Float for Windows 10/11 x64
================================

1. 请先完整解压整个 Vibe-Float-Windows-x64.zip。
   不要直接在压缩包预览窗口里运行程序。

2. 双击 Start-Vibe-Float.cmd（推荐），或双击 VibeFloat.exe。

3. 如果 Windows SmartScreen 出现提示：
   点击“更多信息” -> “仍要运行”。

4. 如果窗口没有出现，请查看启动日志：
   %LOCALAPPDATA%\Vibe Float\startup.log

5. Codex 功能要求已安装并登录 Codex CLI。
   Claude 功能要求已安装 Claude Code。

项目主页：https://github.com/saheru/vibe-float
